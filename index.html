Guide

1. Put your IPA on GitHub
Make an accountGo to github.com and sign up. It’s free.
Create a public repoTap + then New repository. Name it after your app and set it to Public.
Create a releaseOn the repo page, open Releases and tap Create a new release. If you can’t see it, use Request Desktop Website in Safari’s aA menu.
Attach the IPASet a tag like v1.0, then add your .ipa file from Files under the attach area.
Publish releaseReleases take much bigger files than normal uploads.
2. Add it to the store
Open the Store tabFind Add from GitHub.
Paste your repo linkFor example github.com/you/my-app. Tap Find IPA and add.
Or use any download linkA Catbox or GitHub link ending in .ipa works in Add app.
Companion reads the latest release and picks the first .ipa it finds.
3. Make it public
Keep the Public switch onPrivate apps stay on your device only.
Copy JSON to publishTap it under Backup in the Store tab.
Edit store.jsonOpen it in your Companion repo, tap the pencil, paste, and commit.
Wait a minuteThen everyone who opens the site sees your app.
4. Install it
Copy the linkTap Copy on the app, then paste it into Crate.
Open the IPAInstall the saved file with a tool from the Links tab.
Only share apps you made or have permission to share.
